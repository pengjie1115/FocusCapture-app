功能一览

每个功能都围绕一条原则设计：捕获灵感的过程不能比灵感本身更长。

标记说明：标注（高级）的功能需要激活码解锁，首次运行含 14 天全功能体验；未标注的都属于免费版，长期可用。

版本对照

免费版（长期可用）：笔记与待办的记录 / 查看 / 编辑 / 搜索、剪贴板自动捕获、桌面悬浮球、全局热键、沉浸式语音输入、灵感速览与日历标注、待办汇总面板、每日总结、回收站、笔记导入、图片粘贴、拖放保存与上传队列、导出 Markdown 与纯文本。

高级功能（需激活码）：AI 问答（含 Agent 工具）、AI 整理、云同步（WebDAV / 百度网盘 / 得到大脑 / 与云端核对）、导出 Word（.docx）。详见价格页。

捕获

桌面悬浮球

常驻屏幕最前层，不遮挡工作区；输入、速览、语音、设置、退出五大入口一键直达，不透明度可调。

剪贴板自动捕获

复制即自动存为笔记。400ms 防抖过滤瞬态写入，自动去重，可随时开关。

全局热键

不切窗口即可唤起输入窗、开关剪贴板捕获、打开速览、启动语音、唤起 AI 问答与待办汇总，热键可自定义。

沉浸式语音输入

纯 C# 本地语音识别（sherpa-onnx + FireRedASR2），中英双语，深浅双主题，正文占比可调。识别全程离线，音频不上传。

整理

灵感速览

最近笔记面板：今天 / 昨天 / 近 7 天 / 近 30 天 / 自定义区间筛选；标题栏按钮可自由组装；日历上绿点标注每天笔记数、橙点标注待办。

来源与标签

自动记录每条笔记的来源窗口，支持打标签，导出时可选携带。

待办与提醒

一句话记待办，自动解析到期时间；未到期待办在日历上有标注，到期弹提醒。

每日总结

一键汇总当天笔记与待办，快速回顾这一天。

回收站

删除的笔记先进回收站，可恢复，防误删。

AI

AI 问答（高级）

带侧边栏的对话窗口。会话可分组、置顶与批量整理；全局搜索能在全部历史消息里找词，命中处逐词高亮；起手页可以放常用问法，点一下就发出去。输入区支持图文混排——截图直接 Ctrl+V 粘贴、Word / Markdown / PDF 文本自动抽取随消息发送（附件只存本机）。界面明暗可调，名字、头像、欢迎语都能改。

AI 整理（高级）

把一批笔记丢给它，一键理顺——去口水话、并同类、提要点；也能从零散记录里把待办提取出来直接建成真待办。预置 4 条常用规则、支持自定义；整理结果先出预览，你逐条确认后才写回，原文可原样保留。

AI 模型多供应商

同时添加多家模型供应商，各自独立保存 API 地址与密钥，每家有自己的一组模型；可指定默认模型与整理专用模型。API Key 只存本机，不进日志与同步数据。

Agent 工具（高级，随 AI 问答解锁）

AI 问答能直接动手——查笔记、列待办、记灵感、把内容推到云端，不用自己复制粘贴；写操作可开启弹窗确认，改错了有回收站兜底。

Skill 扩展

可以给应用装技能：把一个含 SKILL.md 的文件夹放进技能目录即可，不改写原技能文件；内置技能随应用分发。

得到大脑集成（高级）

可配置「得到大脑」开放平台凭证，笔记一键上传你的知识库。

带走

一键导出

Markdown / JSON / TXT / Word（.docx）四种格式；时间、来源窗口、标签、内容字段可勾选；自动处理重名。其中 Word（.docx）属高级功能，Markdown 与纯文本在免费版即可用。

笔记导入

从其他工具迁移：导入前有预览确认，不怕导错。

加密云同步（可选，高级）

支持 WebDAV（如坚果云）与百度网盘，把笔记与待办加密后存进你自己的网盘——AES-256-GCM 端到端加密，授权码即钥匙。附件按需上传、本地副本可设自动释放；「与云端核对」只读比对网盘里的实际文件，找出已经被删掉的记录并给出清理出口。默认不同步，数据全本地。

热键功能
