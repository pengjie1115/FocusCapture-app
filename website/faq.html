常见问题

关于 FocusCapture 最常被问到的问题。

FocusCapture 是免费的吗？

不是「全功能免费」，而是「免费版 + 高级功能」两档。免费版长期可用，覆盖记录、整理与带走的基本盘；AI 问答（含 Agent 工具）、AI 整理、云同步与 Word 导出属高级功能，需要激活码解锁。两档的具体范围见价格页。

免费版和高级功能分别包含什么？

免费版：笔记与待办的记录 / 查看 / 编辑 / 搜索、剪贴板自动捕获、桌面悬浮球、全局热键、沉浸式语音输入、灵感速览与日历标注、待办汇总面板、每日总结、回收站、笔记导入、图片粘贴、拖放保存与上传队列、导出 Markdown 与纯文本。

高级功能：AI 问答（含 Agent 工具）、AI 整理、云同步（WebDAV / 百度网盘 / 得到大脑 / 与云端核对）、导出 Word（.docx）。

14 天体验期怎么算？到期后会怎样？

第一次打开程序时，14 天全功能体验自动开始，不需要注册、不需要填任何信息，按自然日计算（同一天打开多次只算一天）。体验期内所有高级功能都能直接用。

到期后程序自动降级为免费版——你的笔记、待办、设置全部原样保留，不会锁死、不会删除任何数据；想继续使用高级功能时，在「设置 → 激活码」输入激活码即可恢复。

拿到后在程序「设置 → 激活码」里输入即生效，不需要注册账号、不需要联网验证。请通过本站公布的联系方式获取，其他渠道的激活码我们无法保证有效。

激活码需要保存吗？

需要，请妥善保存。激活码永久有效，一次激活长期可用；重装系统或更换设备时还要用它。

高级功能里的 AI 和云同步会另外收费吗？

不会，FocusCapture 本身不再额外收费。AI 问答使用你自己配置的模型服务，费用按该服务商的计费方式结算，我们不参与；云同步是把内容加密后存进你自己的网盘，若用坚果云等服务的免费额度，请注意其官方流量限制，重度使用建议升级该服务的付费版。

需要安装吗？

不需要。下载得到单个 exe 文件，双击即可运行，无需安装器、无需 .NET 运行时、无需注册账号。

我的数据会被上传吗？

不会。笔记、配置、语音模型全部存储在你自己的电脑上（文档\FocusCapture\ 等本机目录），不上传任何服务器。唯一的例外是你主动开启或使用的可选功能：云同步（端到端加密后存你自己的网盘）、AI 问答（按模型服务的隐私政策处理）与得到大脑上传（你点上传时才发）。

网站会统计我的访问吗？

会，但只统计「量」，不统计「谁」。官网用一个自建的计数服务记录各页面的访问次数和下载按钮的点击次数——不记录 IP 地址、浏览器标识，不记录来源页面，不使用 Cookie，也不做跨站追踪，所以我们无法知道具体是谁访问过、从哪来。爬虫与工具类请求不计入。这些数字只用来判断官网有没有人看、哪几个页面更受关注。

这一条说的是官网。软件本身与此无关：你的笔记、待办、配置全部只存在自己的电脑上，不会上传。

语音识别是离线的吗？

是。语音输入使用纯本地识别引擎（sherpa-onnx + FireRedASR2，中英双语），识别过程不联网、音频不上传。首次使用时会自动从国内镜像下载约 740 MB 的模型文件到本机，之后完全离线运行。

AI 问答需要配置什么？

在「设置 → AI 模型」里添加模型供应商：填服务地址（OpenAI 兼容接口）、API Key，并选好要用的模型。可以同时添加多家供应商，各自独立保存密钥与模型组，还能指定默认模型和 AI 整理专用模型。API Key 只存在你本机的配置文件中，不会上传。不配置 AI 也不影响其他功能使用。

AI 整理会不会改坏我的笔记？

不会偷偷改。整理结果先弹出预览窗，逐条列出「原文 → 整理后」，你可以只采纳其中几条；也可以选择另存为新笔记，原文一个字不动。真要覆盖时，被替换的旧内容会先进回收站。

AI 问答能直接操作我的笔记吗？

可以，需要先在设置里打开「Agent 工具」。打开后 AI 能查笔记、列待办、记灵感、把内容推到云端；写入类操作默认会先在对话里征得你同意，删掉的内容也会进回收站。

能给应用装技能（Skill）吗？

能。「设置 → Skill 扩展」里给出了技能目录，把一个含 SKILL.md 的文件夹放进去即可，应用不会改写技能文件本身；内置技能随应用分发，你本地已有同名技能时不会被覆盖。

和 Windows 自带的剪贴板历史有什么区别？

剪贴板历史只是内容缓存：重启即清、不能整理、没有来源信息。FocusCapture 是笔记库：记录来源窗口与时间、支持标签与筛选、可转待办、可一键导出成 Markdown / Word 等格式长期沉淀。

支持云同步吗？会泄漏隐私吗？

支持可选的云同步，两种方式任选：WebDAV（如坚果云）或百度网盘（需在百度网盘开放平台创建「个人使用」应用，填自己的 AppKey / SecretKey）。传输内容经 AES-256-GCM 端到端加密，授权码即解密钥匙。默认状态下云同步关闭，数据只在本地。云同步属高级功能，需激活码解锁。

误删的笔记能找回吗？

能。删除的笔记先进入回收站，可随时恢复。

如何卸载？会留残留吗？

删除 exe 与本机数据目录即可完全清除：文档\FocusCapture\（笔记与 AI 问答附件）、%AppData%\FocusCapture\（配置）、%LocalAppData%\FocusCapture\（语音模型）。无注册表残留。
