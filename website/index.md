# FocusCapture · 不打断思路的灵感捕获器

> FocusCapture 是一款 Windows 桌面灵感捕获工具：你在任何窗口随手复制一段话、按一个热键说一句话，它就把内容存进本地笔记库，不打断你手头的工作。免安装、双击即用；免费版长期可用，高级功能需激活码解锁。

- **这是什么**：Windows 10/11 桌面灵感捕获工具，免安装，下载后双击即用。
- **能干什么**：剪贴板复制自动存笔记、全程离线的语音输入、待办与提醒、AI 问答与 AI 整理、一键导出 Markdown / Word 等四种格式。记录、整理与 Markdown 导出在免费版即可用；AI 与云同步属高级功能。
- **怎么开始**：到[下载页](download.md)获取 exe，双击运行，无需安装、无需联网注册。首次运行起有 14 天全功能体验，不需要任何操作。

## 核心能力

- **复制即存**：在任何软件里按 Ctrl+C，内容自动进入笔记库，带防抖去重，不打断当前工作。
- **离线语音输入**：纯本地语音识别（中英双语），按热键说话即可成文，音频不上传、不联网。
- **悬浮球常驻**：输入、速览、语音、待办、AI 问答，从悬浮球一键直达，不切换窗口。
- **待办与提醒**：一句话记下待办，自动解析到期时间，日历上标注每天笔记数与待办。
- **AI 问答**：支持图文混排的 AI 对话，可粘贴截图、拖入文档提问；会话可分组、历史消息可全局搜索；模型由你自己配置，能同时接入多家供应商。
- **AI 整理**：一键把散落的笔记理顺、把待办从记录里提取出来，改写前先出预览由你逐条确认。
- **数据全本地**：笔记、配置、模型全部存在你自己的电脑上，不上传任何服务器，删目录即彻底清除。

## 为什么是 FocusCapture

市面上的笔记工具要求你「切到应用 → 新建 → 粘贴 → 保存」，一个灵感四步走。FocusCapture 把它压缩成零步：内容出现的地方，就是它被捕获的地方。捕获之后的所有能力——速览、搜索、待办、导出——都围绕「不打断」三个字设计。

## 与 Windows 自带剪贴板历史的区别

剪贴板历史只存剪贴板内容，且重启即清、不可整理。FocusCapture 记录来源窗口与时间、支持标签与搜索、能转成待办、可导出成 Markdown 和 Word 长文档——它是笔记库，不是剪贴板缓存。
